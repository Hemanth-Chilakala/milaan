## Analyst workflow

Select the scope, reset its demonstration state, then run a real reconciliation. Reset retains sources and decision history. Month reset prepares open tables before the Run timer; a direct completed-month rerun restores them inside the timer. Daily replay retains prior closed groups. Later reversal evidence explicitly reopens the affected group.

The run button locks during execution. Seven passes, a live timer, grouped-source percentage and open-receipt rupees update from committed audit snapshots. Explanations follow reconciliation. Accept, Reject and Assign write a review to Exasol; accounting posting remains a separate approved process.
